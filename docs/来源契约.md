# 资料提供方的格式

`/permit/road.json` 是道路许可给出的可施工街道、米标范围、侧别、深度与分钟窗口，fix 为后发调整。`/owners/catalog.csv` 的测段 range 使用来源自己的零点，`/owners/anchors.json` 每个目录版本给 origin 米，规范米标等于 origin 加 range。范围左闭右开，depth 是可验证最大深度。目录提供报告链接，anchors 中 schedule 为单位当次允许实际领件次数。目录与零点清册的获取不限额。不同单位目录均可访问，报告结果 NoTarget 是有效的无目标记录，Undetected 表示记录未完成。`/crew/ledger.json` 给已交接范围，开始和确认是独立状态。
许可的 required_units 列本工单每个区段需要查明的设施单位，各单位有效资料不互相代替。同次值班中待排与已交接待补可同时存在。
